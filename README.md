# Stackelberg Resource Allocation

Field-calibrated Stackelberg game-theoretic model for cybersecurity resource
allocation in resource-constrained Ghanaian HEIs, using AHP-elicited practitioner
utility weights, causal effect estimation (DoWhy), and simulated annealing
optimization.

**Status:** In development — KNUST CANDO Lab ML Research Programme, 2025–2026.

## Structure
- `data/` — preprocessing pipeline for CERT Insider Threat and CIC-IDS2017 (raw data not included; see access links in proposal)
- `src/` — Stackelberg utility function, SA optimizer, DoWhy causal pipeline
- `config.yaml` — hyperparameters and random seed (42) for reproducibility
- `notebooks/` — exploratory analysis and results visualization
